# Airfoil Geometry Analysis
This project aims to investigate the relationship between airfoil geometry and the aerodynamic performance of the airfoil using computational analysis in Python. I will primarily using Python for this project as this is the programming language I have accumulated the most experience in using. This study will examine how parameters such as camber, thickness, and their locations can influence aerodynamic characteristics.

## Research Question:
   How does the variation in airfoil geometry affect the aerodynamic performance?

## Objectives
- Analyse the specific geometry of various airfoils
- Investigate the effects of camber and thickness
- Develop the necessary python tools for airfoil geometry analysis
- Visualise and compare the aerodynamic performance of different airfoils
- Identify relationships between geometric parameters and performance

## Methodology
This project will make use of Python to:
1. Import airfoil coordinate data
2. Calculate key geometric parameters
3. Visualise airfoil profiles
4. Analyse aerodynamic performance
5. Compare results to other airfoil geometries
